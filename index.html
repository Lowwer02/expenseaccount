🔗 เชื่อมกับ Google Sheets

ทำครั้งเดียว — หลังจากนั้นทุกรายจ่ายจะถูกส่งไป Sheets อัตโนมัติ

  1. เปิด Google Sheets ใหม่
  2. เมนู Extensions → Apps Script
  3. วางโค้ดจากไฟล์ Code.gs ที่ให้ไป
  4. Deploy → New Deployment → Web App
  5. Access: Anyone → Deploy → Copy URL
  6. วาง URL ด้านล่าง แล้วกดบันทึก
